# GeoCentroid website

React (Vite) marketing site based on the GeoCentroid web template: header, footer, home, services mega-menu, and service detail pages for Structural BIM, Architectural BIM, MEPF, AIM, Scan to BIM, and CAD Engineering.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Structure

- `src/components/layout` — Header, Footer, Layout
- `src/components/ui` — buttons, icons, logo, CTA
- `src/data` — navigation and service content
- `src/pages` — routes
- `src/styles` — global and section CSS

## Build

```bash
npm run build
npm run preview
```
